



# Search Strategy

This folder documents the development and final formulation of the search strategy used in the systematic review.

## Structure

- 01_raw/
  Contains intermediate query combinations and automatically generated search logs:
  - Query_combinations.txt → iterative query development
  - search_strategies.json → structured query export from the query generator script

- 02_final/
  Contains the final search strings used for data retrieval:
  - final_query.txt → exact queries applied in Web of Science and Scopus

## Description

The search strategy was developed iteratively by testing multiple query combinations to balance sensitivity and specificity. The final query was selected based on its relevance to the research scope and used to retrieve all bibliographic records included in this study.

Only the final query was used for data collection. Intermediate queries are preserved for transparency and reproducibility. The final query (Query #16) was used for data retrieval on 29 April 2026 in both Web of Science and Scopus.

The manuscript prints `02_final/final_query.txt` as Online Resource 7 (`or-search`).
